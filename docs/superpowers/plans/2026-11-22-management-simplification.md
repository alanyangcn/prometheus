# 管理后台整理实施计划

**目标**：围绕获取订阅、配置节点、设置上游代理组织后台，统一布局与交互，移除维护成本高且与核心用途分离的工具。

**范围**：Vue 后台及相关工具 API；保留摄影首页、协议/传输、旧 KV、订阅格式、在线优选和现有构建方式。初始验收阶段不发布；用户随后授权每轮完成后直接提交、推送和部署。

**方案**：桌面侧栏、手机菜单；概览提供节点摘要和常用订阅，其他客户端格式折叠。节点设置按基础、传输、ECH、高级选项分组。ECH 旧路由兼容跳转。代理目录和远程路径预设连同 API 删除，保留手动代理及验证。网络信息只显示当前请求和手动 IP 查询；删除外部诊断和综合风险评分。保留共享玻璃弹窗、选择框、checkbox、Toast 与明暗主题。

**约束**：保护已有 server/index.ts 和 server/transports/websocket.js 修改；不读取生产秘密、不写生产 KV、不启动已有本地服务。

- [x] 2. 删除退役 UI、API 和无引用代码；合并 ECH，保留旧路由；更新测试和功能矩阵。
