# 功能迁移与验证矩阵

参考基线：cmliu/edgetunnel `a8ab111`，版本 2026-10-08 22:23:27。本次实现保留必要网络算法，重新组织请求运行时与本地管理界面。迁移清单见 migration-inventory.json；迁移算法为 JavaScript，新边界与界面为 TypeScript。

| 功能 | 实现情况 | 已完成验证 | 仍需真实环境验证 |
| --- | --- | --- | --- |
| VLESS / Trojan / Shadowsocks AES-GCM | 协议解析与加解密已迁移 | VLESS/Trojan 向量、SS AEAD 检查 | 三种协议的客户端连接与长连接 |
| WebSocket | 早期数据、上下行、重连与队列已迁移 | 注入标准 socket 的实际 WebSocketPair 数据回传；早期数据边界 | 真实 Workers 并发、长连接及回退 |
| gRPC / XHTTP | 原帧处理与流实现已迁移 | XHTTP 分片首包、必要 padding 校验 | 两种传输的真实客户端及 gRPC 模式 |
| TCP / ProxyIP | 标准 cloudflare:sockets 接口；拨号竞速与连接世代 | 请求上下文隔离、连接世代释放 | 竞速、预加载、回退、断线恢复 |
| SOCKS5 / HTTP CONNECT | 已迁移；修复分片读取与首包残留 | 分片握手、认证拒绝、HTTP 与应用数据同包 | 真实代理认证及持续传输 |
| HTTPS / TURN / SSTP / TLS | 原代理和 TLS 算法已迁移 | 模块加载与构建；代理参数解析 | 各协议真实服务器及握手异常 |
| UDP / DNS / DoH | 保留原有限 UDP 与 DNS 转发范围 | 模块加载与构建 | DNS 与平台限制下的真实转发；不承诺通用 UDP |
| 节点与订阅 | 自动/base64、转换服务与客户端修补已迁移 | 本地地址生成 VLESS 订阅、身份派生 | 外部转换服务、Clash/Sing-box/Surge 客户端导入 |
| 地址来源 | 随机、自定义、远程与 sub:// 解析已迁移 | 地址保存与本地订阅；界面导入入口 | 远程源、优选生成器与异常响应 |
| 配置 / KV / 身份 | 保留旧结构及别名；每请求独立运行时 | 配置保存、认证、Origin、秘密掩码、TG 开关 | 生产 KV 命名空间及旧配置实际迁移 |
| Vue 管理界面 | 本地登录、概览、设置、地址、代理检查、日志、集成 | Chrome 登录→保存→刷新→订阅→退出；无页面异常 | 移动端与生产域名场景 |
| 日志 | 已迁移并脱敏 URL 中的订阅秘密 | token 不落入日志；日志页面 | 真实 KV 规模与外部通知链路 |
| Cloudflare / Telegram | 原用量查询与通知算法；独立凭据设置 | 凭据输入校验及掩码保护 | 真实账号查询和消息发送（本次未发送） |
