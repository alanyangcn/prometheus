# 功能迁移与验证矩阵

Worker 基线：cmliu/edgetunnel `a8ab111`（2026-10-08）。管理界面对照 Worker 加载的单独发布 admin HTML；它与 Worker 提交不保证严格同步。算法为按模块保留的 JavaScript，新应用入口、API 和 Vue 界面使用 TypeScript。界面不再加载远程管理 HTML。

| 账号代理 / 路径模板 | 关闭/SOCKS5/HTTP/HTTPS/TURN/SSTP、全局/名单、可编辑路径模板与第三方预设 |

| 链式代理 | URL 解析、检测、成功后编码/追加、启用自定义模式；输入变更需重验；单测与浏览器操作 |
| 转换服务 / 配置预设 | 参考服务列表、版本与规则读取检查、验证后保存、分组规则预设；受控远程响应与浏览器预设选择 |

| IP 详情 | 地理、ASN、公司、安全标记及参考评分算法；保留未知字段，不把缺失当作通过 |

| 主题 | 系统偏好、浅色/深色切换及持久化；浏览器刷新验收 |

## 验证边界

本次 10 个测试文件、85 项受控检查全部通过。自动化验证、类型/生产构建、Wrangler dry-run 和浏览器验收的本次结果见 `audits/2026-10-10-feature-parity.md`。浏览器使用独立测试 KV；外部检测用受控响应，避免修改用户配置或发送通知。生产构建浏览器检查包含压缩与混淆后的实际文件。

第三方目录、转换器、探测域名、DNS 的真实网络可用性不等于本地工作流验收。没有把源码存在或构建成功描述为所有代理与客户端端到端通过。

仅剔除无功能宗教填充、源码混淆彩蛋、仿 nginx/1101 错误外观、上游源码自动覆盖和装饰动画。密码学、协议 padding、参数编码和有实际用途的管理操作保留。大 CIDR 使用有界确定性采样；按钮替代隐藏长按/拖动手势。
