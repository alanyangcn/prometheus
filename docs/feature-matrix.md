# 功能与验证范围

## 当前管理功能（2026-11-22）

以下为当前后台和服务端支持范围。自动测试、浏览器检查与真实网络验收分别记录。

| 功能 | 当前范围 |
| --- | --- |
| 导航与概览 | 桌面侧栏、手机菜单；节点摘要、三种常用订阅、折叠其他格式和单节点链接 |
| 节点配置 | 基础信息、协议传输、高级连接、ECH；同页保存/取消，ECH DNS 与指纹校验；旧 ECH 路由兼容跳转 |
| 表单状态 | 加载、错误、重试；显示未保存修改，普通路由切换前确认丢弃；显式退出登录结束会话 |
| 上游代理 | 手动 PROXYIP、自动 PROXYIP、自有代理账号验证、全局/名单、手动路径模板；移除公共代理目录、第三方 PROXYIP 检测、远程模板预设及其 API |
| 连接信息 | 仅当前请求的 CF 元数据、手动 IP 基础查询和原始来源标记；移除浏览器出口检测、站点延迟和自定义风险评分 |
| 订阅与转换 | 保留所有订阅格式、在线优选、地址导入和链式节点；转换规则预设按需读取；生成器需识别 Prometheus 客户端标识，不兼容时返回 503 |
| 日志 | 关键词、类型和 UTC+8 日期筛选，导出当前筛选结果，加载/错误/空结果状态 |

协议、传输、旧 KV、身份派生、摄影首页和单文件构建方式不在本轮删减范围。生产实网连接、外部转换/代理服务器可用性仍需真实客户端验收。本轮自动测试、产物与隔离浏览器验收见 [整理验收记录](audits/2026-11-22-management-simplification.md)。

## 网络与服务端

| 功能 | 已实现 | 已验证 | 尚未完成的真实环境验收 |
| --- | --- | --- | --- |
| VLESS / Trojan / SS AES-GCM | 原解析、加解密、分流算法 | 协议向量、AEAD 检查 | 各客户端的实际长连接 |
| WS / gRPC / XHTTP | 早期数据、首包、流、队列与回退 | 标准 socket 注入的 WS 回传、gRPC/XHTTP 实际受控双向流、分片/padding | 真实 Cloudflare 与客户端组合 |
| TCP / PROXYIP / 竞速 | 标准 cloudflare:sockets，请求隔离、连接世代 | 上下文隔离、连接释放 | 实网竞速、恢复和长连接 |
| SOCKS5 / HTTP CONNECT | 原认证与连接算法，分片握手修复 | 分片、拒绝、握手与首包同包 | 真实认证与持续传输 |
| HTTPS / TURN / SSTP / TLS | 原算法保留 | 参数解析、模块和构建 | 真实服务器及异常握手 |
| DNS / DoH / 有限 UDP | 保留参考协议支持范围 | 模块与构建 | 实际 DNS 与平台限制；不承诺通用 UDP |
| 订阅生成与转换 | 自动/base64/Clash/Sing-box/Surge/Loon/Quantumult X、原客户端修补 | 本地地址实际订阅、身份派生、格式入口与导入 URI | 第三方转换可用性及实际客户端导入 |
| 配置 / KV / 认证 | 兼容旧结构/别名，独立请求运行时；掩码凭据；写入 Origin 检查 | 认证/权限、配置交互、可选字段、地址、秘密和 TG 开关 | 旧用户数据的逐个实际迁移 |

## 验证边界

自动测试覆盖协议解析、请求隔离、配置读写、鉴权、日志、订阅、管理工具、Toast 及构建资源。当前品牌标识和生成器兼容由独立行为测试验证。

标准构建、Wrangler 部署预检、单文件产物集成测试和浏览器交互分别验收。第三方服务、真实客户端长连接和隧道实网可用性不以本地测试替代。
