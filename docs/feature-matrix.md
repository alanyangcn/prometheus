## 验证边界

本次 10 个测试文件、85 项受控检查全部通过。自动化验证、类型/生产构建、Wrangler dry-run 和浏览器验收的本次结果见 `audits/2026-10-10-feature-parity.md`。浏览器使用独立测试 KV；外部检测用受控响应，避免修改用户配置或发送通知。生产构建浏览器检查包含压缩与混淆后的实际文件。

第三方目录、转换器、探测域名、DNS 的真实网络可用性不等于本地工作流验收。没有把源码存在或构建成功描述为所有代理与客户端端到端通过。

仅剔除无功能宗教填充、源码混淆彩蛋、仿 nginx/1101 错误外观、上游源码自动覆盖和装饰动画。密码学、协议 padding、参数编码和有实际用途的管理操作保留。大 CIDR 使用有界确定性采样；按钮替代隐藏长按/拖动手势。

### 地址库、实用工具与浏览器优选的入口归属

- 地址文本编辑、上传、导出和订阅接口归入“优选订阅 → 自定义订阅”。
- 浏览器优选归入同一区域的“开始优选”弹窗；来源、探测参数、筛选、测速与导出保留。选中结果写入订阅地址草稿，由优选订阅页面统一保存。
- IP 详情归入概览网络卡片的 IP 查询入口；Worker 网络元数据和手动 IP 查询归入概览的“网络详情”。链式代理已归入自定义订阅。
- 删除地址库、实用工具、浏览器优选三个独立 tab、路由与旧视图文件，保留它们使用的功能模块和管理 API。

此次迁移通过 TypeScript 检查；未部署，第三方网络链路的真实可用性仍需在当前浏览器网络中确认。

### 节点配置与详细配置信息对照

节点配置使用专用表单，按参考页面 renderUI、updateProtocol、updateGrpcModeVisibility 与 saveConfig 对齐：订阅名称、HOST/HOSTS、UUID、PATH、协议、SS 加密/TLS、传输、gRPC 模式/UA、指纹、ALPN、证书验证、随机路径、0-RTT 与客户端 TLS 分片。SS 字段仅在 Shadowsocks 下显示，gRPC 字段仅在对应传输下显示；可选字段按后端返回是否存在展示。本项目后端支持 ALPN，无须沿用参考页面针对旧版 Worker 的版本门槛。

HOSTS 通过域名输入框打开编辑弹窗；UUID 只读并提供说明；PATH 在完整节点路径字段存在时允许编辑，并规范化前导斜线和注释。关闭 SS TLS 与手动指定 ALPN 需确认，SS/gRPC 禁用 0-RTT，SS 无 TLS 禁用 ECH 和分片。两个客户端分片选项互斥。

移除通用高级字段区中的运行数据展示；节点字段不再受专家模式限制。保存和取消仅在有修改时启用，保存节点字段、订阅名称及明确发生的 ECH 联动，不提交其他模块的配置快照。此次修改通过 TypeScript 检查，未进行部署或真实客户端连接验证。

### 日志入口对照（2026-10-11）

参考 Worker 的 KV 日志入口为管理页面访问（Admin_Login）、配置保存（Save_Config）、地址保存（Save_Custom_IPs）、配置重置（Init_Config）和普通订阅获取（Get_SUB）。配置、地址、重置及订阅原已保留；Vue 管理页面绕过旧 HTML 路由后，访问记录缺失，现由鉴权后的配置读取入口补齐，覆盖管理界面加载配置的访问。只对同类型、同 IP、URL、UA 的管理访问做 30 分钟去重；配置保存、地址保存及重置每次成功均记录，避免被旧去重条件吞掉。

参考 Get_Best_SUB 显式关闭 KV 写入，其通知用途已随 Telegram 删除，不恢复该通知和已删除的 Cloudflare 用量设置日志。日志保留 OFF_LOG 开关、URL 脱敏和容量上限；不记录密码、请求体或代理凭据。
